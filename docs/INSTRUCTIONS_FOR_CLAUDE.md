## Task 1: アプリアイコン作成（優先度：高）

**対象:** `assets/icon/`

1. **アイコン画像を作成:**
   - サイズ: 1024x1024 PNG
   - ファイル名: `app_icon.png`
   - 配置先: `assets/icon/app_icon.png`

2. **デザインガイドライン:**
   - コンセプト: 「空気の痕跡」「溶ける」「ミニマル」
   - 背景色: #0A0A0F（ダークテーマ）
   - 参考: `assets/icon/README.md`

3. **生成コマンド:**
   ```bash
   dart run flutter_launcher_icons
   ```
