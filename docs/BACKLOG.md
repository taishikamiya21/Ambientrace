## ステータス凡例

| ステータス | 意味 |
|:--|:--|
| `Open` | 未着手 |
| `In Progress` | 対応中 |
| `Done` | 完了 |
| `Won't Fix` | 対応しない（理由を備考に記載） |

## 優先度凡例

| 優先度 | 意味 |
|:--|:--|
| `Critical` | リリースブロッカー。必ず修正が必要 |
| `High` | リリース前に修正すべき |
| `Medium` | リリース後でも可だが、できれば修正 |
| `Low` | 改善案。次バージョン以降でも可 |
