# Ambientrace デザインシステム v1.0

> ミニマルで空気感のあるデザイン言語。アンビエントデータアプリケーション向け。
> 「写真ではなく、感覚を記録する。」

---

## 1. デザイン哲学

### 基本原則

| 原則 | 説明 |
|:---|:---|
| **Atmospheric Minimalism（空気感のミニマリズム）** | 感覚を呼び起こすもの以外はすべて削ぎ落とす。UIを減らし、想像力を増やす。 |
| **Dark-First（ダークファースト）** | 暗いキャンバスがアンビエントデータ（色、光、雰囲気）を視覚のヒーローにする。 |
| **OOUI（オブジェクト指向UI）** | 「Trace」オブジェクトがファーストクラスの市民。タスクではなくオブジェクトで操作する。 |
| **意味 > 時間** | セマンティックな意味（アンビエントタグ）がタイムスタンプよりも視覚的に優先される。 |
| **不透明度による階層** | 白色テキスト/要素の不透明度を変化させ、新しい色を導入せずに深度を作る。 |

### ビジュアルアイデンティティ キーワード

`minimal` `atmospheric` `dissolving` `ambient` `dark` `ethereal` `quiet`

### 2.6 動的カラー導出

カードとシェア画像は、Traceの抽出カラーパレットから背景グラデーションを導出する：

```
_desaturateAndDarken(Color color):
  HSL → 彩度 * 0.3 → 明度 = 0.08 → アルファ = 0.6

ShareableTraceCard 背景:
  color1 → HSL 明度 = 0.1, 彩度 = 0.3
  color2 → HSL 明度 = 0.05, 彩度 = 0.2
```

タグピルのアクセントカラーはパレットカラーを `0.3〜0.4` の不透明度で使用する。

## 6. エレベーションとシャドウ

本デザインシステムは**ドロップシャドウを一切使用しない**。深度は以下の方法で表現する：

1. **背景の不透明度**: 低い不透明度 = より奥に位置
2. **ボーダーの不透明度**: 控えめなボーダーでサーフェス境界を作る
3. **グラデーション背景**: パレットカラーからの `LinearGradient`
4. **前景オーバーレイ**: 背景色へのグラデーションフェード（詳細ヒーロー）

### 10.2 コンテンツ階層（Traceオブジェクト）

全画面共通の情報優先順位:

```
1. MEANING（意味）  → プライマリアンビエントタグ（ヒーロータイトル）
2. FEELING（感覚）  → カラーパレット（グラデーションバー / スウォッチ / ヒーローバナー）
3. CONTEXT（文脈）  → Atmospheric Time + 正確な時刻 + 場所 + 天気
4. STORY（物語）    → AI生成 Reconstructed Memory
5. META（メタ情報）  → 座標、騒音レベル
```

### 10.3 Atmospheric Time（空気感のある時間）

正確なタイムスタンプの代わりに主役として表示する時間表現。

| 時間帯 | 英語 | 日本語 |
|:---|:---|:---|
| 0:00 – 3:59 | Late Night | 深夜 |
| 4:00 – 5:59 | Dawn | 夜明け |
| 6:00 – 9:59 | Morning | 朝 |
| 10:00 – 12:59 | Midday | 昼 |
| 13:00 – 15:59 | Afternoon | 午後 |
| 16:00 – 17:59 | Dusk | 夕暮れ |
| 18:00 – 20:59 | Evening | 夜 |
| 21:00 – 23:59 | Late Night | 深夜 |

表示階層: Atmospheric Time（目立つ）→ 正確な時刻（控えめなメタデータ）。

### 10.4 グラデーションオーバーレイ

## 13. 新プロジェクトへの適用

### 13.1 クイックスタートチェックリスト

1. `Scaffold.backgroundColor` を `#0A0A0F` に設定
2. 白色不透明度テキスト階層を使用（セクション2.3参照）
3. ヒーローテキストには `w200` / `w300` ウェイトを適用（幻想的な質感）
4. セクションタイトルには `UPPERCASE` + `字間: 2` + `w600` を使用
5. コンテナパターン: `bg white 0.05, border white 0.1, radius 12-16px`
6. シャドウなし — 不透明度とグラデーションのみで深度を表現
7. システムフォントのみ使用（SF Pro / Roboto）

### 13.2 カラーシステムの適応

ベースカラーシステム（`#0A0A0F` + 白色不透明度）はアプリ非依存。適応する場合：

- 背景と不透明度スケールはそのまま維持
- `color.ai-accent`（amber）を各プロジェクトのフィーチャーアクセントカラーに置換
- 動的パレット導出を各ドメインのカラーソースに置換
- `color.surface`（`#1A1A2E`）は浮き上がった要素用にそのまま維持
