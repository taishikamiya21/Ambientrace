# Ambientrace（アンビエントレース）企画書

## 📌 アプリ概要

**コンセプト：** 「空気の『痕跡（トレース）』だけを辿る」

写真そのものは保存せず、撮影した瞬間の**環境データ（コンテキスト）**だけを記録するアプリ。
後から見返したとき、データをもとに**当時の景色を想像で再構成する**という、記憶とデータの新しい体験を提供する。

---

## 🎯 ターゲットユーザー

- 日常をライトに記録したい人
- プライバシーを気にしつつ思い出を残したい人
- 「情報のミニマリズム」に共感する人

---

## ✨ 独自の視点

> **「あえて写真を残さないことで、記憶を鮮明にする」**

- 写真は「解析の種」として使われるだけで、保存されない
- 代わりに「空気感のログ」だけが残る
- 例：「あの日の15時、風が強くて、カフェにはコーヒーの香りとジャズが流れていた」

## 🔧 機能仕様

### Phase 1（初回リリース）

#### Gemini API 利用枠について（目安）
ユーザー自身のGoogleアカウントでAPIキーを取得して利用する場合の無料枠（Free Tier）の目安です。
*   **モデル:** Gemini 1.5 Flash
*   **レート制限:** 15 RPM（1分間に15回まで）
*   **1日あたりの制限:** 1,500 RPD（1日1,500回まで）
    *   *注: 2025年12月以降、一部の無料枠が縮小されている可能性があるため、APIコンソールでの確認を推奨。*
*   **注意事項:** 無料枠のデータはGoogleの学習に利用される可能性があります。

#### タグ付け/ラベリングの方針（Ambient Tagging）
単なる物体認識（「コップ」「机」）ではなく、**「空気感・状況・感覚」**を記録する方針に変更します。
*   **Atmosphere（雰囲気）:** "Quiet Morning"（静かな朝）, "Busy Street"（賑やかな通り）
*   **Sensory（感覚）:** "Warm Sunlight"（暖かい日差し）, "Cold Air"（冷たい空気）, "Coffee Aroma"（コーヒーの香り）
*   **Action（文脈）:** "Working at Cafe"（カフェでの作業）, "Waiting for Train"（電車待ち）

これを実現するため、Geminiへのプロンプトを工夫し、具体的な物体名よりも抽象度や情緒性の高いフレーズを抽出します。

| 機能 | 詳細 |
|------|------|
| **カメラ撮影** | ファインダーあり。撮影後、写真は保存されない |
| **センサーデータ取得** | GPS（位置情報）、天気、気温、周辺の音（デシベル） |
| **基本画像解析** | ML Kitによる自動タグ付け（「犬」「空」「食べ物」など） |
| **カラーパレット抽出** | 撮影した写真から主要な色を抽出して保存 |
| **ログ一覧表示** | 日時・場所・タグ・カラーパレットのリスト表示 |
| **感覚フィードバック** | シャッター時や溶解時のハプティックフィードバック（触覚） |
| **シェア機能** | "Trace Card"（データ化された記憶）のSNS共有画像生成 |

### Phase 2（コンセプト鮮明化："Less is More"）

**目標:** Ambientraleを「純粋でミニマルな雰囲気記録ツール」として研ぎ澄ます。

| 変更 | 理由 |
|------|------|
| **AI Sketch機能を削除** | 画像生成は「データから想像する」哲学に反する。ユーザー自身の想像力を尊重 |
| **Step Count表示を削除** | フィットネスアプリではなく「Ambient（環境）」に集中 |
| **AtmosphereセクションにNoise Level統合** | 音は「雰囲気」の一部として天気・気温と同じセクションへ |

**保持する機能（Hero Features）:**
- ✅ **Color Palette** - 記憶を呼び起こす視覚的トリガー
- ✅ **Ambient Labels** - 「Quiet Morning」のような文脈ラベル
- ✅ **Weather/Temperature** - 環境コンテキスト
- ✅ **Noise Level** - 周囲の音も「雰囲気」の一部
- ✅ **AI Story** - データが「雰囲気」を捉えたか確認するためのセカンダリ機能

## 🎨 UX演出

1. **「現像」プロセスの逆転**
   - シャッターを切ると、写真がじわじわと「データ（数字や文字）」に溶けて消えていくアニメーション

2. **データからの想像**
   - 色・キーワード・環境データから、頭の中で当時の景色を再構成する体験
